# finance-tracker
 📊 Finance Tracker System

🚀 Overview
The Finance Tracker System is a web application designed to help users manage their income, expenses, and savings efficiently. It automates transaction categorization, provides personalized budget forecasts, and delivers actionable financial insights through a user-friendly dashboard.

---

✨ Features
- 🔹 Income & Expense Logging – Easily record transactions with categories.
- 🔹 Automated Categorization – AI-driven classification of spending patterns.
- 🔹 Budget Forecasts – Personalized predictions for savings and expenses.
- 🔹 Interactive Dashboard – Visual reports with charts and graphs.
- 🔹 Secure Data Storage – Transactions stored safely in MongoDB/MySQL.
- 🔹 Scalable Architecture – Built with modern full-stack technologies.

⚙️ Installation & Setup
1. Clone the repository
   `bash
   git clone https://github.com/your-username/finance-tracker.git
   cd finance-tracker
   `

2. Install dependencies
   `bash
   npm install
   `

3. Set up environment variables
   Create a .env file in the root directory:
   `
   PORT=5000
   MONGOURI=yourmongodbconnectionstring
   JWTSECRET=yoursecret_key
   `

4. Run the backend
   `bash
   npm run server
   `

5. Run the frontend
   `bash
   cd frontend
   npm start
   `
